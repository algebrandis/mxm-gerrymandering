This folder contains scripts and generated adjacency matrices for U.S. counties and county-equivalents using U.S. Census county adjacency data.

For each state or territory:

&emsp;`XX_county_list.csv` gives the county ordering used by the matrix.

&emsp;`XX_county_adjacencies.csv` gives the corresponding adjacency matrix.

These were generated by `generate_adjacency_matrix_for_all_states.py`.

`us_census_data_county_adjacency.csv` comes from the U.S. Census Bureau, available at: 

&emsp;&emsp;https://www2.census.gov/geo/docs/reference/county_adjacency/county_adjacency2026.txt

These graphs are intended as a source of undirected graphs of varying sizes, to be used for small-scale testing.
